# Part 1
1. TanStack Query is a library that makes it easier to do queries from an API/DB. It does this by being able to condense multiple useState and useEffect calls into a simple useQuery. UseQuery provides many functional tools and capabilities such as having built in isPending, isFetching, isError, error, isSuccess, isLoading, and many others along with the data. It also provides the capability of having caching. When it runs a query, via a query function that uses fetch, the information is stored in the cache via a key. When the query needs to run again it fetches data from the cache using the key and only needs to run the query again when there is a new focus on the time and it is past staleTime or we force a refresh. This helps response time seem instant since it just has to pull it from the cache. 
2. 
    1. A dashboard would be an application where TanStack Query would be useful because you want to pull data frequently to update your site, if you were to do this with a normal useState and useEffect you would have to have a manual sync button to refetch all of the data. With TanStack you can set your staleTime to indicate how long you want to keep the data before refreshing to make sure it stays up to date. When it is passed the staleTime since writing to the cache it will trigger a refresh when there is a new focus on the site. 
    2. It would be useful to have TanStack Query for applications that use forms. Without TanStack Query you need to make the change via the API/DB and then refetch the data again, but with TanStack you can update the API/DB and then mutate what is in the cache and invalidate the keys so that everything, cache included is up to date. 
    3. TanStack would be useful in more complex apps where a user might be going to different pages a lot and then coming back to a page they were previously on. This is because TanStack caches the data that it queries so if a user returns back to a page where TanStack has already gathered that data it can just grab it from the cache rather than having to refetch the data, provided that the data hasn't expired past the staleTime
3. For an application that only needs to fetch the data once because it doesn't change that often, would be a use case where you are better off using useEffect instead of TanStack, because TanStack is built towards caching and easily fetching updated data without desturbing the app. If something isn't going to change much and you only need to get the data once useEffect works great.
